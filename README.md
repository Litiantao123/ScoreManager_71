# ScoreManager_71
简易Java控制台学生成绩管理系统
> 学号后两位：71

## 项目介绍
基于Java语言开发的控制台小程序，实现学生信息录入、成绩查询、删除记录、平均分统计功能。本项目为《开源文化运动》课程作业，用于练习GitHub开源仓库管理、分支协作、Issue交流等开源流程。

## 运行环境
JDK 8及以上版本

## 运行方式
1. 编译：`javac src/StudentScore.java`
2. 运行：`java src.StudentScore`

## 功能清单
- 添加学生学号、姓名、成绩
- 根据学号查询学生成绩
- 删除指定学生记录
- 统计全班平均分
